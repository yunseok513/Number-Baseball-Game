# Number Baseball Game

사람과 컴퓨터가 서로 상대의 4자리 비밀번호를 먼저 맞히는 콘솔 게임입니다. 0부터 9 사이의 중복 없는 숫자 네 개로 각자 비밀번호를 정한 뒤 번갈아 추측을 주고받으며, 자리와 숫자가 모두 일치하면 Strike로, 숫자는 있지만 자리가 다르면 Ball로 알려줍니다. 먼저 4 Strike를 받아내는 쪽이 승리합니다.

플레이어의 비밀번호는 프로그램에 입력하지 않습니다. 컴퓨터가 추측을 내놓으면 플레이어가 자신의 비밀번호와 직접 비교해 Strike/Ball 결과를 입력하는 방식이라, 상대에게 자신의 비밀번호를 알려주지 않는다는 원래 규칙을 그대로 지킵니다. 반대로 컴퓨터의 비밀번호는 프로그램 내부에서만 쓰이고, 플레이어의 추측은 프로그램이 자동으로 판정합니다. 컴퓨터는 가능한 모든 숫자 조합(5040가지)을 후보로 들고 있다가, 매 턴 받은 Strike/Ball 힌트와 맞지 않는 후보를 지워나가는 방식으로 다음 추측을 고릅니다.

## 실행 방법

```
javac -d out src/main/java/com/numberbaseball/game/*.java
java -cp out com.numberbaseball.game.NumberBaseballGame
```
